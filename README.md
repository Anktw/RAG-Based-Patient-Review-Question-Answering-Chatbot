# RAG-Based Patient Review Question Answering Chatbot

Retrieval-Augmented Generation (RAG) system to answer questions from patient reviews. This repository contains a Jupyter notebook that demonstrates how to build a RAG-based chatbot for answering questions based on patient reviews. The system ingests review data, vectorizes it, and allows users to ask questions that are answered using the relevant review information. Uses Gemini-2.5 to generate context-aware answers with a Gradio chatbot interface.

# Quick Start
-----------
1. Create and activate a Python environment.
2. Install dependencies (example):

```bash
pip install -r requirements.txt
```

3. Open and run `Healthcare_RAG_Intelligence_System.ipynb`.

Repository Structure
-------------------
- `Healthcare_RAG_Intelligence_System.ipynb` — walkthrough and runnable examples.
- `dataset/` — data files.
- `notebook/` — additional notebooks or experiments.
